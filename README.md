# Holographic-Fan

This project is a Persistence of Vision (POV) hologram display built using an Arduino Nano, a WS2812B LED strip, an L298N motor driver, a 130 DC motor, and a KY-003 Hall effect sensor. The build consists of 5 fan blades made from cardboard, each carrying a segment of 28 addressable RGB LEDs connected in a daisy chain through a slip ring. As the motor spins the blades at high speed the LEDs flash in precise sequences triggered by the Hall effect sensor detecting a magnet on the rotating assembly, creating the illusion of a floating 3D image in midair. The slip ring allows power and data signals to pass from the stationary Arduino and breadboard to the spinning blades without tangling the wires. The project was built and tested component by component, verifying the LED strip, motor control, and Hall sensor independently before final assembly. Future upgrades include swapping the Arduino Nano for an ESP32 to enable WiFi controlled image uploading, Bluetooth control from a smartphone, and more complex multi frame animations.
